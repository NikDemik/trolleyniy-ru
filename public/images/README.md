# Изображения

Реальные фотографии пока не добавлены. Ничего не скачивается с внешних сайтов.
Компонент Media показывает условную схему, если src равен null; реальные изображения
рендерятся через next/image с зарезервированными пропорциями.

Рекомендуемые пути после получения согласованных файлов:

- /images/hero/production.webp
- /images/products/trolley.webp
- /images/products/mono.webp
- /images/products/festoon.webp
- /images/brands/anneng.webp
- /images/projects/<slug>/<filename>.webp

Задавайте содержательный alt. Не используйте изображения других брендов как ANNENG.
